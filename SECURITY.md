# Security Policy

veil-forum is Alpha software. It is not an anonymity guarantee and must not
be used for high-risk activity without an independent threat-model review.

Please report suspected vulnerabilities privately to the repository
maintainers rather than opening a public issue with exploit details. Include
the affected version, deployment mode, reproduction steps, impact, and any
relevant logs with secrets removed.

Do not include passwords, tokens, private keys, real user data, Onion keys,
I2P Destination keys, or database files in a report.

Security fixes are evaluated against the current `master` branch. There is no
guaranteed response time or security support commitment for Alpha releases.
